# Support

For installation, billing or account questions, use the relevant product website and its published support route. For technical problems in a public repository, use that repository's issue tracker.

Before reporting a technical problem, check the project's README and existing issues. Include the product version, operating system, reproduction steps, expected result and actual result. Share only redacted logs and screenshots.

Feature requests should explain the task you want to accomplish and why the current experience falls short.

For suspected vulnerabilities, follow [SECURITY.md](SECURITY.md). Support availability and release status are defined by each product; this repository is not a customer case system.
