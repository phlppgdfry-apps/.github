## Apps you can try today

Native Mac analytics and a public GitHub profile lab, built by [Philippe Godfroy](https://github.com/phlppgdfry) in Belgium.

### ClickTrack

**macOS · Public download available**

See clicks, keystrokes, scrolling and focus patterns in one dashboard. Activity data stays on your Mac; typed content is not recorded.

[**Download the latest release →**](https://github.com/phlppgdfry/ClickTrack/releases/latest) · [Website](https://clicktrackapp.com) · [Source](https://github.com/phlppgdfry/ClickTrack)

### DevDNA

**Web + CLI · Public demo available**

Explore a public GitHub profile's language palette and activity patterns. Compare profiles and export a shareable card.

[**Open the demo →**](https://devdna-xi.vercel.app/phlppgdfry) · [Analyse your profile](https://devdna-xi.vercel.app) · [Compare profiles](https://devdna-xi.vercel.app/compare) · [Source & CLI](https://github.com/phlppgdfry/devdna)
