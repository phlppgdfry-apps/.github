## Ownership decision

For now, the organisation owns the directory and shared resources; the personal account owns the product repositories. Links on the profile point directly to those authoritative sources. Moving a repository is a separate delivery change rather than a cosmetic profile edit.

Before a future transfer, inventory deployment connections, release downloads, package names, GitHub Pages, Actions permissions and external app installations. After transfer, check those integrations and update local remotes and public links. Keep an explicit owner for the migration.
