## ClickTrack

**Private activity analytics for macOS.**

ClickTrack brings clicks, keystrokes, scrolling, focus sessions, streaks and activity trends into a Mac dashboard. It counts input events rather than recording the text you type; the product documentation describes local storage and its macOS Accessibility permission.

- [Official website](https://clicktrackapp.com)
- [Latest public release and downloads](https://github.com/phlppgdfry/ClickTrack/releases/latest)
- [Installation and privacy information](https://github.com/phlppgdfry/ClickTrack#install)
- [Source repository](https://github.com/phlppgdfry/ClickTrack)

The repository currently lists macOS 13 or later. Check the release notes for the actual build you install. Signing, distribution and commercial activation can differ between releases; follow the product's current instructions rather than assuming every build has the same purchase flow.

## DevDNA

**A GitHub identity lab, in the browser and terminal.**

Explore language palettes and public activity patterns, compare profiles and export a shareable card. The app explains how traits are inferred and makes the limits of its sample visible.

- [Open the app](https://devdna-xi.vercel.app)
- [Try Philippe's public profile](https://devdna-xi.vercel.app/phlppgdfry)
- [Compare two profiles](https://devdna-xi.vercel.app/compare)
- [Repository and CLI setup](https://github.com/phlppgdfry/devdna#run-locally)
- [Releases](https://github.com/phlppgdfry/devdna/releases)
- [Data and methodology](https://github.com/phlppgdfry/devdna#what-the-data-actually-means)

DevDNA uses public GitHub data. Language shares are not measures of proficiency, and activity traits are not a developer ranking. Local snapshots stay in the browser; see the project's browser-local data documentation for details.

## Support and contributions

Use a product's own support route for installation, billing or account questions. For reproducible technical issues, use its repository issue tracker. Explain the version, environment, steps, expected result and actual result; redact logs and screenshots.

Before contributing, read the project's licence and contributor instructions. For suspected vulnerabilities, follow the relevant [private reporting route](../SECURITY.md).
